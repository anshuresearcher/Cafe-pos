How to read these numbers

API response data counts response body bytes measured by the POS server. It excludes TLS, network framing, and browser-to-Supabase Storage image downloads.

Database result estimate is based on sampled PostgreSQL rows serialized as JSON. It is an estimate, not database wire bytes and not exact Supabase Shared Pooler Egress.

Supabase billed egress remains the authoritative total in your Supabase dashboard. Monitoring batches are best-effort on Vercel and can be lost if a function instance ends before flushing.
